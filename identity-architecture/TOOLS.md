# TOOLS.md

Store your environment-specific notes here — API endpoints, credentials locations, device names, preferred voices, SSH hosts, anything that's unique to your setup.

## Why Separate from Skills?

Skills define _how_ tools work. This file is for _your_ specifics — the infrastructure and preferences that make your environment yours.
