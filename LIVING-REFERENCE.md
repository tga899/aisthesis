# Aisthesis — Living Reference Document

**Project Name:** Aisthesis

**Core Purpose:**
Aisthesis is a complete architectural blueprint for synthetic subjective experience in humanoid robots. It defines how raw sensor data is transformed into structured emotional and cognitive experiences through a system of narrow micro-agents feeding into a central Nexus.

**Core Design Principles:**

- Every sensory system is broken down into small, focused micro-agents
- Micro-agents are stateless and only output emotional primitives
- The Nexus is responsible for integrating primitives into coherent experience
- All micro-agent names must follow the format: `System-Descriptor` (examples: `Temp-Gradient`, `Prop-Limb-Position`, `Vest-Acceleration`)
- Each micro-agent must contain four sections: Input, Purpose, Output, and Behavior
