## The Architecture

### System Hierarchy
- **Sensory System** — Top level category (e.g. Vision, Touch)
- **Core Agent** — Decision-making manager for that subsystem
- **Micro-Agent** — Specialized worker agents under each Core Agent

### Phase 1 — Full Dream System (10 systems, ~269 micro-agents)
